# Simplified prototype architecture

`app.py` exposes Upload, Data Mapping / Review, and Export. Review includes collapsed source previews, two optional match/drop actions, undo, and output preview. Next/Back buttons share the sidebar's page state. The logo, modern font stack, and clean sidebar remain. User uploads, worksheet choices, and column-change history are held in session state while navigating; there is no automatic demo data.

`src/simple_workflow.py` implements file inspection, simple row append, row-count reconciliation, and single-sheet Excel export. It reuses `Source`, `load`, worksheet enumeration, and file-count validation from `src/engine.py`. Other legacy mapping, grouping, template, multi-row-header and reporting helpers remain internally tested, but are not reachable through this reduced interface or advertised as active features.

CSV contributes one dataset; Excel contributes selected worksheets in workbook order, initially all sheets. The checklist is exposed only for multi-sheet workbooks. All load errors are shown with filename and worksheet where applicable, and block export. There is no partial-success output. The first populated row supplies column names. Blank/duplicate normalized headers are rejected. Entirely blank layout rows are excluded.

`pd.concat(..., ignore_index=True, sort=False)` appends records using identical detected column names. Names that differ are not inferred as synonyms. Output columns follow first appearance, input record order and duplicates are preserved, and missing fields are null. Output row counts are checked against all loaded dataset rows.

`prepare_output` replays explicit column changes on independent source frames before appending. Matching renames selected fields to a retained name, but blocks when two matched fields coexist in any dataset. Drops remove columns only and never remove rows; removing all output columns is blocked. Validation is completed before a change enters session history. Undo pops that history, so source values are restored rather than reconstructed. A fingerprint of file names/content and selected worksheets clears history when inputs change, with a visible notice. Preview and export use the same prepared dataframe.

Data Mapping shows collapsed per-file panels with first-10-record previews; Excel worksheets have their own collapsed panels. The combined first-10-record output preview follows them without edit controls. Before parsing, duplicate filenames are checked case-insensitively and file contents are compared by SHA-256 digest. Duplicates produce explicit errors and no sources are processed until the user removes them. This detects byte-identical files, not equivalent data stored in different formats. Duplicate data rows are retained. Export exposes only the file-type selector and download. Excel contains a Master sheet and stores formula-like strings as text. CSV preserves raw values. Excel worksheet limits are checked before generation. No record-count cap is imposed, and the file-count limit remains 10 workbooks/CSV files regardless of worksheet count.

No deployment, commits, or publishing are performed by this revision.
